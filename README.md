# Fiado

Pra anotar quem te deve, contar as sextas furadas e mandar a cobrança pronta no WhatsApp.

- Funciona sem internet depois do primeiro acesso.
- Os dados ficam só no aparelho (nada vai pra servidor). Faça backup em **Ajustes → Backup**.
- Tema claro/escuro, cores, ícone e textos configuráveis em **Ajustes**.

## Instalar no iPhone

1. Abra o link do app no **Safari**.
2. Toque em **Compartilhar** → **Adicionar à Tela de Início**.

## Atualizar

Edite `index.html` e aumente `VERSION` em `sw.js` (ex.: `fiado-v2`) pra os aparelhos baixarem a versão nova.
